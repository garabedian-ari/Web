NARI — PURE HTML / CSS / JAVASCRIPT

Bestanden
- index.html: structuur en teksten van de website
- styles.css: volledige styling en responsive ontwerp
- script.js: mobiel menu, prijsindicatie, FAQ, animaties en contactformulier
- assets/nari-hero.png: hero-afbeelding

Lokaal bekijken
Open index.html in een moderne browser.

Online plaatsen
Upload index.html, styles.css, script.js en de volledige map assets naar de
hoofdmap van je hostingpakket. De onderlinge paden moeten hetzelfde blijven.

Voor publicatie aanpassen
- Vervang contact@nari.be door het echte e-mailadres.
- Controleer de indicatieve prijzen en abonnementen.
- Koppel het formulier eventueel aan een echte formulierdienst of backend.

Techniek
De website gebruikt geen framework, CMS, buildproces of externe bibliotheken.
Alles werkt met gewone HTML5, CSS3 en JavaScript.
